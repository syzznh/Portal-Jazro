JAZRO Learning & Student Progress Portal

A web-based platform designed to help JAZRO administrators manage student information, classes, assessments, learning materials, certificates, and report cards. The system also allows parents to monitor their children's learning progress and access educational resources through a centralized portal.
The portal supports multiple JAZRO branches (KTG, CHU, CYB, and KTH) using a shared database.

Admin Portal
- 
- Manage student and class information
- Manage assessments and student results
- Upload learning materials and certificates
- Manage report cards and online class recordings

 Parent Portal
 -
- View children's profiles and enrolled classes
- Access learning materials and online assessments
- Monitor assessment results and report cards
- View certificates and online class recordings

Project Purpose
- To provide a centralized, organized, and accessible platform that improves student progress monitoring and simplifies administrative management across JAZRO branches.

Database Setup

Install and open XAMPP.

Start Apache and MySQL.

Open phpMyAdmin at http://localhost/phpmyadmin.

Create or select the database required by the project.

Open the Import tab.

Select the jazro_portal_v2.sql file from this repository.

Click Import or Go to execute the SQL file.
