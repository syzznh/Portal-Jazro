## File Placement Guidelines

| Folder | Files to Upload |
|---|---|
| ADMIN PORTAL | All administrator-related PHP files |
| PARENT PORTAL | All parent-related PHP files |
| config | Database connection and configuration files |
| css | All CSS files |
| images | Logos, icons, banners and other images |
| js | All JavaScript files |
| Root Directory | Main system files and database SQL export |

## Team Guidelines

1. Always upload files into their correct folders.
2. Do not upload files randomly into the root directory.
3. Do not create duplicate files.
4. Do not rename existing files without informing the team.
5. Do not overwrite another team member's work.
6. Always test your code before pushing changes to GitHub.
7. Keep file and folder names consistent.
8. Inform the team before making major changes.

## Important Notes

- Keep the existing folder names unchanged.
- Check the latest version of the repository before editing.
- Database changes must be documented.
- Never upload database passwords, FTP credentials or other sensitive information to GitHub.

**Please follow this structure to maintain an organized repository and ensure smooth collaboration among all team members.**
